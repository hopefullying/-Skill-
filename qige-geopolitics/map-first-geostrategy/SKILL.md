## I — 方法论骨架 (Interpretation)

这个方法的起点是：**位置先于动机**。解释国家行为时，不先猜领导人想什么，先画地图：

1. 该主体连接哪几块区域（海陆交汇、能源通道、文明/市场边界）？
2. 它掐着哪些咽喉（海峡、港口、管道、山口、缓冲带）？
3. 它有战略纵深吗（可退让空间、人口与工业分布）？
4. 谁最需要控制它？谁最怕失去它？——由此推出“必争”与“宿敌”。
5. 用同一套逻辑检验历史：通道被封 = 生存被锁，衰落往往是逐点失守（苏联败亡案例）。

关键断言是“位置即命运”：换一个政府坐在同一位置，结构压力不变，行为模式趋同。

## A1 — 书中的应用 (Past Application)

### 案例 1: 伊朗=欧亚十字路口
- **问题**: 美国为什么必须打伊朗？
- **方法论的使用**: 看地图——伊朗连接南亚/中亚/西亚/欧洲/波斯湾，高原俯视中东。
- **结论**: 拿下伊朗=控制十字路口与能源通道；不打伊朗等于放弃美元石油霸权。
- **结果**: 2026 年美伊开战，作者视之为预测兑现。

### 案例 2: 苏联败亡的通道解释
- **问题**: 苏联为什么解体？
- **方法论的使用**: 追踪其出海口链条（旅顺/釜山/福建/越南/阿富汗南下印度洋）逐点被封。
- **结论**: 出海口与通道被封锁是结构性失败，而非单纯经济崩溃。

### 案例 3: 霍尔木兹=43% 石油
- **问题**: 为什么控制海峡比打军舰更重要？
- **方法论的使用**: 算咽喉流量——霍尔木兹每日石油占全球 43%。
- **结论**: 封锁咽喉即锁喉美元，是成本最低的战略武器。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户问“某国地理位置到底有什么影响/为什么是战略要地”。
2. 用户想预判某场冲突会扩大到哪些邻国/通道。
3. 用户看新闻遇到陌生地名（海峡、走廊、缓冲国），想快速定位其战略权重。
4. 用户在评估“一带一路/能源通道”类议题。

### 语言信号

- “这个位置重要吗 / 有什么用”
- “为什么 X 总被大国盯上”
- “查一下霍尔木兹/马六甲/某走廊的作用”
- 英文: “why is this location strategic / what does the map say / chokepoint analysis”

### 与相邻 skill 的区分

- 与 `industrial-base-power-check` 的区别：本 skill 先回答“它在哪里、谁会争”，工业 skill 回答“它有没有本钱撑住”。
- 与 `great-power-master-switch` 的区别：本 skill 用地理推“谁必争”，总开关 skill 用中美博弈推“事件属于哪一步”。

## E — 可执行步骤 (Execution)

1. **画连接图**
   - 完成标准: 列出该主体连接的区域、邻国矩阵、主要通道与距离
2. **找咽喉与纵深**
   - 完成标准: 标出 1-3 个关键咽喉（海峡/港口/山口/管道）和战略纵深条件（面积/地形/人口/工业分布）
3. **推必争逻辑**
   - 完成标准: 回答“谁最需要控制它、谁最怕失去它”，给出 2 个以上利益相关方
4. **推宿敌与行为**
   - 完成标准: 预测该主体的核心安全焦虑与外部干预方向
5. **标边界**
   - 完成标准: 明确指出地理解释力的上限（制度、技术、国内政治可能改写位置的含义）
   - 判停条件: 若对象是纯内陆且无资源/通道价值，转用其他框架

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯国内政治（选举、立法）问题——地理不解释政党竞争。
- 纯经济/金融事件（汇率、债务）——地理是背景不是机制。
- 微观战术/装备评估——本 skill 是战略层，不是作战层。

### 作者在书中警告的失败模式

- 只看地图忽略工业与组织（“有位置没本钱”照样被拿捏）。
- 把“位置重要”说成“位置决定一切”，忽略时代技术变化（海峡在导弹时代的意义已改变）。

### 作者的盲点 / 时代局限

- 地理决定论对“同一位置、不同时代”的解释力有限（大航海时代的海峡与 AI 时代的海峡权重不同）。
- 低估制度与联盟对地理约束的改写能力（新加坡、瑞士案例）。

### 容易混淆的邻近方法论

- 地缘政治教科书常识（无判定流程）
- 历史地理考据（无预测意图）
