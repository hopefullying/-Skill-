# 消耗战与马拉松时间观

## R — 原文 (Reading)

> “俄罗斯不输，但不能停……就是互相消耗最好……他们都不赢咱家就赢了。”
>
> — 七哥，2024-2-21

> “大变局多极化是一场马拉松，这是纯是一种消耗战。但是时间肯定是在咱这边。”
>
> — 七哥，2026-5-24

---

## I — 方法论骨架 (Interpretation)

把长期竞争当作**耐力赛**而不是短跑：

1. 先定义“赢”的最小条件——有时“谁都没赢”就是你的赢（不赢即赢）。
2. 判断“谁更能熬”：工业存量、财政承受力、内部团结、时间偏好。
3. 强者策略：控节奏、小火慢炖、持续放血，拒绝速决诱惑。
4. 弱者策略：赌窗口期速决——因为拖下去必输。
5. 把“谁先急”当作信号：先沉不住气的一方暴露底牌，等于输了一半。
6. 用“压轴后发”作为权力信号：从容等待本身就是实力展示。

核心反直觉点：**克制不是软弱，是实力**——越强越不急于决战。

## A1 — 书中的应用 (Past Application)

### 案例 1: 俄乌消耗战的目标设定
- **问题**: 俄罗斯该不该速胜/该不该停？
- **方法论的使用**: 设双向约束——不能败、也不能赢太顺利；互相消耗最好。
- **结论**: “没有赢家，他们都不赢咱家就赢了。”

### 案例 2: 中美马拉松
- **问题**: 美国为什么急、中国为什么不急？
- **方法论的使用**: 比耐力（工业/组织/时间偏好）+ 看谁先急。
- **结论**: 大变局是马拉松，时间在中国这边；美国“一天一个样”是被逼的表现。

### 案例 3: 小火慢炖放血
- **问题**: 实力占优时为什么不正面决战？
- **方法论的使用**: 强度与实力成反比——越强越用低烈度手段放血。
- **结论**: 把对手拖入“不能停、又赢不了”的状态是上策。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户面对长期竞争（价格战、技术竞赛、地缘对峙）问“该怎么打”。
2. 用户问“时间站在谁那边/谁能耗得起”。
3. 用户评估“拖延/以拖待变”是否合理。
4. 用户想判断对手“着急”意味着什么。

### 语言信号

- “谁能耗得起 / 时间站在谁那边”
- “以拖待变 / 放血 / 压轴”
- “为什么强者不急 / 谁先急谁输”
- 英文: “who can outlast / long game strategy / attrition”

### 与相邻 skill 的区分

- 与 `proxy-war-cost-trace` 的区别：成本账算“谁在出成本”，本 skill 定“谁的耐力更强、该拖还是该赌”。
- 与 `structural-necessity-forecast` 的区别：马拉松是节奏观，必然性预测是事件结局推演；两者常组合（拖到某结构触发）。

## E — 可执行步骤 (Execution)

1. **定义赢的最小条件**
   - 完成标准: 用一句话说明“不赢即赢”是否适用（是否可接受双输/拖平）
2. **比耐力**
   - 完成标准: 工业存量、财政、内部团结、时间偏好各给 1 条证据
3. **定策略**
   - 完成标准: 强者=控节奏拖长；弱者=赌窗口速决，并给出反例条件
4. **监控“先急”信号**
   - 完成标准: 列出 2 个以上“对方开始着急”的可观察信号（政令反复、舆论加码、越级行动）
   - 判停条件: 若已进入资源耗尽期（弹药见底、财政爆表），转为“谁能先止血”分析
5. **标退出条件**
   - 完成标准: 写明“拖”在什么证据下失效（对方外援到位、己方内部爆裂）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 速胜窗口明确且已打开（再拖就错过）——此时拖是错的。
- 己方资源已近枯竭——耐力模型不适用，要先止血。
- 纯短期交易/战术决策——本 skill 是战略节奏。

### 作者在书中警告的失败模式

- 把“时间在我这边”当口号而不验证耐力参数。
- 只算对方被消耗，不算自己消耗（内部政治、财政、机会成本）。

### 作者的盲点 / 时代局限

- 低估长期消耗对己方社会的反噬（语料极少算“咱家”的消耗成本）。
- “不战而胜”概率被反复强调，但缺乏可证伪的时点。

### 容易混淆的邻近方法论

- 耐心鸡汤（无耐力参数）
- 拖延战术（无目标函数）
