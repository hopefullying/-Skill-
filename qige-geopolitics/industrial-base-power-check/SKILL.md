# 工业体系国力评估

## R — 原文 (Reading)

> “工业谁抓的工业谁强，但是得看体格的，你得有战略纵深，人口得更多。”
>
> — 七哥，2024-3-8

> “你没有工业，给你图纸，啥都给你，你给我噪音……光玩制造业，资本想收割他的时候，一波就给他带走了。”
>
> — 七哥，2024-3-5-8

---

## I — 方法论骨架 (Interpretation)

把“国家实力”理解为**有地基的体系，而不是资产清单**：

1. 地基三件套：工业体系（重工业+电力+供应链）、人口/人力质量、战略纵深。
2. 上层建筑（金融、美元、科技、航母、品牌）都依赖地基；没有地基，上层会被收割或封锁。
3. 判断抗压能力先看“自主闭环度”：关键材料、能源、设备、粮食能否自给/替代。
4. 判断战争前景看“工业动员+库存+后勤”，不看武器代差。
5. 判断制裁效果看“目标国的替代能力”，不看制裁数量。
6. 判断“制造业转移”前景看“承接国的地基”，不看工资与订单。

核心反直觉点：**技术领先不等于实力领先**——技术必须由工业体系承接，图纸不是产能。

## A1 — 书中的应用 (Past Application)

### 案例 1: 越南/印度为何接不住制造业
- **问题**: 越南工资更低，为什么替代不了中国制造业？
- **方法论的使用**: 查地基——电力不足、无重工业体系、供应链不完整。
- **结论**: 没有地基的转移会被资本一波收割。
- **结果**: 作者断言“工业化窗口已关闭”，厂子终会回流。

### 案例 2: 稀土反制
- **问题**: 中国用什么对抗技术封锁？
- **方法论的使用**: 算产业链位置——中国掌握稀土加工环节。
- **结论**: 用上游材料锁喉美西方军工与高科技。
- **结果**: 作者称这是“美西方自大航海以来首次在工业体系核心领域被反打”。

### 案例 3: 美国去工业化→霸权空心
- **问题**: 美国为什么不能再输一场战争？
- **方法论的使用**: 对比工业存量——以前输了回去两年能恢复，现在“工业也没了”。
- **结论**: 失去工业地基后，军事失败将直接转化为体系崩溃。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户问“A 国和 B 国谁更有实力/谁能赢”。
2. 用户讨论制裁、封锁、贸易战的真实效果。
3. 用户评估“制造业转移/去风险/脱钩”的前景。
4. 用户分析某国经济结构时想跳过 GDP 数字看本质。

### 语言信号

- “谁实力更强 / 谁能扛住制裁”
- “制造业转移到越南/印度/墨西哥靠谱吗”
- “供应链/重工业/电力/产能”
- 英文: “who can outlast whom / how effective are sanctions / can X replace China in manufacturing”

### 与相邻 skill 的区分

- 与 `map-first-geostrategy` 的区别：地理回答“谁会争”，本 skill 回答“争不争得赢、扛不扛得住”。
- 与 `hegemony-collapse-chain` 的区别：本 skill 评估单国地基；霸权链评估体系塌方顺序。

## E — 可执行步骤 (Execution)

1. **列地基清单**
   - 完成标准: 电力、重工业、供应链完整度、工程师/技能人口、动员制度各给出 1 条证据
2. **查自主闭环**
   - 完成标准: 判断能源/粮食/关键材料/高端设备中哪些依赖外部，标出断供风险
3. **做上层剥离**
   - 完成标准: 把金融/科技/军备解释为地基的函数，指出“哪些优势是借来的”
4. **推抗压结论**
   - 完成标准: 输出制裁效果、战争承受力、制造业转移前景三个判断
   - 判停条件: 若对象是纯服务型/金融型经济体，把“地基”替换为“网络/制度/人才”并说明偏离
5. **标反例**
   - 完成标准: 说明什么证据会让结论反转（如技术革命改变承接方式）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 评估金融中心（新加坡、瑞士、香港）——地理与制度权重超过工业。
- 纯技术对比（AI 算法、芯片设计）——本 skill 看的是承接与量产能力。
- 微观企业竞争力评估——本 skill 是国家/体系级。

### 作者在书中警告的失败模式

- 把“会造东西”等同于“能打赢”——还需人口、纵深、组织（体格）。
- 认为技术封锁必然失败——前提是己方工业体系能承接突破。

### 作者的盲点 / 时代局限

- 低估服务化、AI 与金融对“工业=一切”的改写。
- 低估人口老龄化、内需、财政等长期约束（语料中极少讨论）。

### 容易混淆的邻近方法论

- 产业链研究（微观企业层）
- 军备对比（数量层）
