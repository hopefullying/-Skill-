# 从政治文本反向建模认知操作系统

## R — 原文 (Reading)

> “你的任务不是总结主播讲了哪些新闻，也不是复述主播的观点，而是从一批主播的文字稿中，逆向提炼出这个主播在地缘政治领域的认知操作系统……不要收集观点，要提炼产生这些观点的规则。”
>
> — 本项目分析提示词（已在 84 篇语料上执行验证）

---

## I — 方法论骨架 (Interpretation)

这个方法把“一个人怎么想问题”当作可逆向工程的对象：

1. 先清洗语料（去掉口语、带货、互动、单次事件细节），只留与认知相关的表达。
2. 用概念频次做跨文本统计，找出全语料反复出现的变量（如“工业”“霸权”“地理”），作为候选认知变量的证据。
3. 抽取关键句式（“为什么/因为/如果…就/本质/核心/一定会/必然”），定位他的因果链与预测规则。
4. 精读代表文本，确认规则在多个主题、多个年份、多个国家对象上重复出现。
5. 把“观点”还原为“产生观点的规则”（例如“中国不会放弃台湾”→“核心领土与战略纵深不可替代，国家会为此承担高成本”）。
6. 单独做“反事实测试”与“认知盲区”扫描：他如果 X 不存在，是否仍作同样判断？他系统忽略什么？
7. 每条规则标置信度（高/中/低），单次出现的内容只记为“偶发观点”。

产出是一份“认知操作系统说明书”，目标是：给一个他从未讲过的新事件，也能推演他会注意什么、忽略什么、如何预测。

## A1 — 书中的应用 (Past Application)

### 案例 1: 从 84 篇文字稿重建《七哥论国际》COS
- **问题**: 语料含大量口语、带货与新闻复述，怎么提炼稳定认知规则？
- **方法论的使用**: 全库概念统计（84 篇中“工业”88%、“霸权”89%、“地图/海峡”50%+）+ 因果/预测句式抽取 + 12 篇代表全文精读。
- **结论**: 提炼出“地理→工业→中美总开关→必然性预测”四层引擎，以及 6 个稳定预测模式。
- **结果**: 产出了可外推的《认知操作系统说明书》，并用“中亚某国政权更迭”等新场景做了推演测试。

### 案例 2: “中国不会放弃台湾”的规则还原
- **问题**: 直接记录观点会变成立场清单，无法外推。
- **方法论的使用**: 追问“为什么”，找到其底层规则（安全纵深、海上通道、统一的历史叙事）。
- **结论**: 规则化表达为“核心领土与战略纵深具有高度不可替代性，国家会承担较高成本”。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户有一批主播/政客/评论员的文字稿或视频转写，想知道“他的分析框架是什么”。
2. 用户要预测某评论员对未发生事件的态度，需要可外推的模型。
3. 用户想对比多个评论员的认知差异（谁的变量权重不同）。
4. 用户在做内容研究/舆情研究，需要把“观点”结构化。

### 语言信号

- “反向建模/蒸馏他的认知系统/认知操作系统”
- “他为什么总是这么判断/他看世界的框架是什么”
- “把这批文字稿变成能预测他会怎么想的规则”
- 英文: “reverse-engineer how this commentator thinks / build his cognitive OS / distill his analytical framework”

### 与相邻 skill 的区分

- 与 `map-first-geostrategy` 等分析型 skill 的区别：本 skill 分析“人”，其他 skill 分析“世界”；本 skill 的产出正是其他人的方法论。
- 与简单摘要的区别：摘要回答“他说了什么”，本 skill 回答“他的什么规则产生了这些说法”。

## E — 可执行步骤 (Execution)

1. **清洗与统计**
   - 完成标准: 输出清洗规则清单 + 全语料概念频次表（哪些概念出现在 30%+ 文本）
2. **句式抽取**
   - 完成标准: 得到“因果句/预测句/定义句”三类上下文样本，每条标来源文本
3. **精读与跨文本验证**
   - 完成标准: 每个候选规则有 ≥2 个独立语境佐证；否则标“低置信度/偶发”
4. **规则化与盲区扫描**
   - 完成标准: 观点→规则改写完成；反事实测试与盲区各列出 ≥3 条并附文本证据
5. **输出说明书**
   - 完成标准: 含一句话画像、变量权重表、预测模式、信息过滤器、盲区；可对“新事件”做推演示范
   - 判停条件: 若语料 <3 篇或全是二手转述，停止并说明样本不足

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 只有单篇文本或单条观点（无法做跨文本验证）。
- 用户要的是“他讲了什么”的新闻摘要。
- 需要事实核查或立场定性（亲美/反美）——那不是认知模型。

### 作者在书中警告的失败模式

- 把“政治立场”当“认知系统”：要用变量使用频率，而不是标签。
- 用单个观点推整个世界观：必须多个文本→重复模式→规则。
- 给主播硬贴理论标签（“他是现实主义者”）而不解释他为什么这样表现。

### 作者的盲点 / 时代局限

- 语料的时间窗口（2023-2026 高冲突期）会放大“冲突与衰落”叙事；换和平期样本可能得到不同模型。
- 直播业态本身奖励“必然性话语”，模型可能高估其确定性偏好。

### 容易混淆的邻近方法论

- 简单书摘/观点汇总（无规则化）
- 人格画像（关注性格而非认知机制）
