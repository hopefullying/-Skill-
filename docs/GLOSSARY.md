## 三、动作与战术词

| 词 | 含义 |
|---|---|
| **拖字诀** | 以时间换空间的不对称消耗策略；专用于弱势方对付速决型强权 |
| **放血 / 消耗** | 让对手持续付出成本而不给它决战机会 |
| **战略外移** | 把对手对己方的消耗引向第三地（东欧、中东），自己在两条线上减压 |
| **压轴（出场/待变）** | 不抢跑、不先下场，等他人相互消耗后再以主力定局。其表述被概括为「高筑墙、广积粮、压轴出场」三步（出处见 SOURCES.md） |
| **开战即决战** | 一旦动手就一次打掉对手反击能力，不给缓冲时间 |
| **立威之战** | 与"立国之战"对应：一动手就彻底改变格局的那一仗 |
| **打扫外围 / 扫清支点** | 先逐个清掉核心目标的周边支点，把它孤立成孤点 |
| **引蛇出洞** | 己方不动，用压力迫使对手先动以暴露底牌 |
| **统战价值** | 一个弱者被援助前必须先"打出来"的价值：扛住首轮 + 造成有效杀伤 |
| **买单人** | 消耗战中最终承担成本的非交战方（如海湾国家） |
| **看门狗 / 棋子 / 棋手** | 代理人的三级分层；看门狗可换主人，棋手才有独立战略 |
| **反围剿** | 表面是多方围剿一方，实际围剿发起者自己被战场/同盟/通道拖住 |
| **拆家运动** | 不求战场占领，而是逐点摧毁对手在中东的基地与依托 |
| **换赛道 / 你打你的我打我的** | 不被对手节奏牵走，另开战场改变规则 |
| **虚张声势** | 高成本兵力/威胁的高调展示，用于掩盖手段不足（用维持成本可验证） |
| **硬撑 / 绷不住** | 口头强硬与实际能力脱节，随时间暴露 |

## 五、使用提醒

1. **代称带立场**：这些词（二狗子、飞猴、鬼子）自带贬义和阵营预设，
   在非本语料的对话中直接引用会造成误解，引用时请加引号并标明来源。
2. **量化阈值是他给的**：如"55% 生死线""稀土 60 天"，属于他的情景设定，
   不是公认标准，转引时不可当作外部事实。
3. **部分术语无定义**：如"口子""统战价值"缺可操作阈值，见各 skill 的 B（边界）段。
