## 三重验证标准

| 代号 | 标准 | 判定问题 |
|---|---|---|
| V1 | **跨域复现** | 这个方法在 ≥2 个不同时间点/不同主题上被独立使用过吗？（排除一次性发挥） |
| V2 | **产出可检验** | 用它能否产出一个明确的、可被证伪的判断或行动建议？（排除纯态度） |
| V3 | **体系独特性** | 它不是通用常识，而是"七哥体系"特有的切入方式吗？（排除"要具体问题具体分析"这类） |

三票全过 → 进入阶段 2；两票 → 降级进 GLOSSARY 或 DIGEST；一票及以下 → `rejected/`。
